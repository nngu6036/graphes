# ==============================================================================
# FINAL EXPLICIT GDSM EXPERIMENTS
# ==============================================================================
#
# Datasets:
#   1. Community-small
#   2. Ego-small
#   3. QM9
#   4. ZINC
#
# Seeds:
#   41, 42, 43, 44, 45
#
# Experimental protocol:
#   - Community-small / Ego-small: generate 1,024 graphs per seed.
#   - QM9 / ZINC: generate 10,000 molecules per seed.
#   - Graphlets: g3, g4, g5 (g345 experiment configuration).
#   - GDSM eigendecomposition backend: CPU.
#   - Training / generation device: cuda:0.
#   - Synthetic evaluation: GraphRNN MMD protocol + ORCA.
#   - Molecular evaluation: raw-valid metrics, NSPDK, FCD, QED.
#
# IMPORTANT:
#   - All commands are explicit; no seed loop is used.
#   - All experiment results present in the original source file are retained.
#   - Recorded outputs are stored in Bash no-op heredoc blocks:
#
#         : <<'RESULTS_...'
#         ...
#         RESULTS_...
#
#     Therefore the results remain readable in this file but are NOT executed.
#   - If no result was present for a dataset/seed in the source file, the script
#     says "No recorded result in source file"; no metric is fabricated.
#
# ==============================================================================
